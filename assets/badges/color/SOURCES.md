# Flat colour badges

Original local SVG presentation inspired by the compact, uppercase, flat badges
in the owner's screenshot reference. The labels, grouping and palette are adapted
to Daniyar's confirmed Java backend stack and public links. No external badge
generator, tracking service or statistics workflow is used.

Badge height is 28px. Names remain readable text inside each self-contained SVG,
and the README supplies descriptive alt text. Brand-colour labels sit beside
original Devicon icons on a dark chip. Badges wrap individually on narrow screens.

Embedded icons: Java, Spring (Boot, Security and Data JPA), PostgreSQL, Docker,
Git, Maven, GitHub Actions, LinkedIn and GitHub. Icon geometry and gradients are
retained, with prefixed IDs/references. The GitHub mark is recoloured from dark
to light for contrast; its original file is preserved. The Spring leaf identifies
the Spring ecosystem, rather than a separate official logo for every module.
Other badges are text only.
