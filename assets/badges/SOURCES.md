# Compact stack badges

These local SVG badges use original flat backgrounds, thin borders and readable names.
The small badge format is inspired by the Shields badges in
[lengway's README](https://github.com/lengway/lengway/blob/HEAD/README.md).
The selection, three groups and muted petrol/slate colours follow Daniyar's own stack.
There is no dependency on a live badge service.

Eight badges embed existing Devicon artwork:

The original geometry, colours and gradients are retained. Viewports position and
scale the icons; internal IDs and references are prefixed to keep them distinct.
The Spring leaf identifies the Spring ecosystem; the label names Spring Boot.
Other badges contain text only.
