## Lab notes

<details>
<summary>open /lab — a look inside the local video analyzer</summary>

One of the things I work on in **Forte Cash Audit**:

```text
video
  │ PyAV
  ▼
frames + timestamps
  │ Qwen3-VL / llama.cpp
  ▼
local observations
  │ temporal rules
  ▼
evidence + explanation
```

The output is a signal for a person to review. Original frames and timestamps
help us examine both useful detections and mistakes.
