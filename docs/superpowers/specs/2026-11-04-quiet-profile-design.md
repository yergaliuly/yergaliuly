# Quiet profile

Дата: 2026-11-04. Владелец просит спокойный профессиональный профиль по примеру [lengway](https://github.com/lengway), без неона. Это небольшая редакционная переработка существующего Profile README, без нового продукта или платформы.

## Решение

Изучен [исходный README lengway](https://github.com/lengway/lengway/blob/HEAD/README.md): имя и направление, сгруппированный стек, короткие текстовые разделы и контакт. Берём простую иерархию и конкретность. Чужие навыки, опыт, контакты и лозунг не копируются.

Рассмотрены минимальная визитка (слишком мало сведений о работах), компактное текстовое портфолио (рекомендация исполнителя: соответствует запросу и сохраняет четыре настоящих проекта) и вариант с баннером/бейджами (лишняя графика для выбранного направления). Используется компактное портфолио на обычном Markdown. Все варианты бесплатны; Markdown проще поддерживать и читать на телефоне, не требует внешних изображений или сервисов.

## Оформление и границы

Нативные шрифты, цвета и тема посетителя GitHub; выравнивание слева, обычные заголовки и абзацы. В README нет изображений, анимации, JSON-биографии, витринных карточек, emoji-заголовков или счётчиков. Текст должен помещаться в короткую страницу и естественно переноситься на узком экране.

Слово «стартапер» понимается как желаемая сдержанная подача. Не заявляем статус founder, работу в Silicon Valley, seniority, production-готовность или владение всеми языками. Оригинальные ресурсы, лицензии, PDF и каталог сертификатов сохраняются. Настройки аккаунта в этот запрос не входят.
