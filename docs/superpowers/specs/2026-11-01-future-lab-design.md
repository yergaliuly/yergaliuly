# Daniyar's Lab: holographic workbench

Дата: 2026-11-01. Это развитие уже выбранного Daniyar's Lab: владелец сохраняет основу, просит более футуристичную графику и красиво подписанный стек по четырём новым референсам.

## Исследование и решение

Изучены [beautiful-profile-readme](https://github.com/topics/beautiful-profile-readme), каталог [MaxRohowsky](https://github.com/MaxRohowsky/best-github-profile-readme), исходные README [MacroPower](https://github.com/MacroPower/MacroPower), [BrunnerLivio](https://github.com/BrunnerLivio/BrunnerLivio), [DIMFLIX](https://github.com/DIMFLIX/DIMFLIX), [HiradEmami](https://github.com/HiradEmami/HiradEmami), а также [GitSkins](https://www.gitskins.com/) и его [описание тем](https://www.gitskins.com/docs/themes).

Полезные приёмы: логотип вместе с читаемым названием (MacroPower), единая авторская тема вместо случайных бейджей (BrunnerLivio), группировка командных проектов (DIMFLIX), самостоятельные SVG-панели и понятные ссылки (HiradEmami). GitSkins и приложенные изображения задают объём, cyan/violet-свет и стеклянные слои. Это визуальные ориентиры, не источник чужих цифр или авторской графики.

Варианты для этой доработки:

| Вариант | Сложность и поддержка | Совместимость | Решение |
| --- | --- | --- | --- |
| Готовые внешние виджеты | Быстрее начать; зависимость от сервиса, условий и обновлений | Разная; не все изображения сайта являются README | Не добавлять новую зависимость ради оформления |
| Плотный HUD со счётчиками | Много мелкого текста и постоянно меняющихся данных | На телефоне нужен отдельный дизайн | Не подходит к текущей цели |
| Собственная голографическая Lab | Умеренная разовая работа; локальные SVG и GIF | Markdown, picture, details; без сервера | Выбрано исполнителем в рамках запроса и сохранённой концепции |

## Визуальная система

- Цвета: deep space `#080B18`, glass `#121A35`, violet `#A48AFF`, cyan `#55E8F5`, mint `#75F4C3`, text `#EEF3FF`.
- Типографика: Segoe UI / Arial для крупной графики и названий; Consolas / monospace только для небольшой схемы запроса. Основной текст остаётся нативным текстом GitHub.
- Ключевой образ: объёмное ядро модели на стеклянных слоях, соединённое с API и хранилищем. Это иллюстрация области работы, не мониторинг реальной системы.
- Одна спокойная анимация в hero: импульс запроса, слабое движение ядра и света; без мигания и имитации текущей активности. 72 кадра / 7,2 секунды, статичная версия для reduced motion.
- Проекты: четыре самостоятельные объёмные обложки с таймерами, картой, видеокадрами и документами. Описания и ссылки остаются текстом.
- Toolkit: восемь основных карточек с оригинальным логотипом, названием и назначением; четыре командные карточки внутри details. Desktop 4 колонки, mobile 2 колонки через picture/source. Полный подтверждённый стек остаётся сгруппированным текстом.

```text
hero: name + holographic workbench
native identity / links / JSON
four builds: cover + real contribution
toolkit: 4 x 2  →  2 x 4 on mobile
details: full stack + team cards
details: analyzer notes
certificates / LinkedIn
```

## Границы

Не добавлять новые технологии без свидетельств, проценты владения, чужие звёзды, трофеи или вымышленные результаты. Не менять каталог сертификатов, PDF, аккаунт и проектные репозитории. Прежние Lab-ресурсы сохранить: новые файлы помещаются в `assets/lab/future/`. Оригинальные Devicon и MIT-атрибуция сохраняются; встроенные копии логотипов получают только новое окружение.

Это уточнение существующего дизайна по явному запросу владельца, без повторного полного brainstorming. Локальная реализация и проверка разрешены запросом; перед новой публикацией нужен конкретный пакет и подтверждение по AGENTS.md.

## Проверка

Отрисовать и просмотреть hero, четыре обложки и обе ширины Toolkit. Проверить XML, самостоятельность SVG, читаемость названий, GIF и пропорции. GitHub Markdown API должен сохранить picture/media/srcset и оба details. Проверить относительные пути, ссылки, отсутствие приватных данных и неизменность каталога/PDF/старой графики. Настоящий профиль на 1280 и 390 px проверяется после разрешённой публикации; локальные картинки не выдаются за такую проверку.
