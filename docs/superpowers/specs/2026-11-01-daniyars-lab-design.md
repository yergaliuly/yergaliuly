# Daniyar's Lab

Дата: 2026-11-01. Владелец выбрал предложенную концепцию Daniyar's Lab с ночным рабочим пространством, анимацией, обложками проектов, иконками и раскрывающимся lab-блоком.

## Зачем меняем

Опубликованное техническое портфолио оказалось слишком серым и похожим на резюме. Нужно больше цвета, характера и движения при сохранении настоящих проектов и проверяемого содержания.

## Рассмотренные направления

- **Daniyar's Lab — выбрано:** ночная лаборатория, фиолетово-голубой свет, собственная иллюстрация, один GIF и обложки проектов. Умеренный объём графики; статические файлы без платных сервисов.
- **Space Lab:** космическая станция и проекты-миссии. Простая геометрия, но меньше связи с работой владельца.
- **Daniyar.exe:** набор окон и панелей. Больше отдельных визуальных элементов и обслуживания; GitHub не превращается в интерактивную ОС.

## Содержание и композиция

1. Единственный анимированный баннер: ночная лаборатория, свет монитора, дождь/город за окном, путь запроса API → model → response. Спокойный цикл 6–8 секунд, без вспышек. Статичный SVG сохраняется как исходник и вариант для reduced motion, если GitHub сохранит picture/source.
2. Имя Daniyar Yergalyuly и направление Java Backend / Applied AI остаются обычным текстом. LinkedIn и KDvibers — настоящие ссылки.
3. About — небольшой подсвеченный JSON-блок с подтверждёнными сведениями об AITU, направлении и команде.
4. Четыре проекта с собственными векторными обложками: FocusDuo/таймеры, HackAtlas/события, Forte Cash Audit/видео и evidence, StudyMate/конспекты и тесты. Названия, описания и ссылки остаются текстом.
5. Компактные цветные иконки основных технологий; остальной стек и технологии команды раскрываются. Сохранять различие личного вклада и командного стека.
6. `open /lab` — настоящий details-блок со схемой локального видеоанализатора, без реальных банковских кадров, приватных видео и выдуманных результатов.
7. HackAlem и избранные сертификаты под общим блоком Proof of work; полный каталог сохраняется без изменений.

## Визуальные решения исполнителя

- Палитра: midnight `#101028`, panel `#1C1940`, violet `#B799FF`, cyan `#67E8F9`, warm light `#FFA879`, text `#F4F1FF`.
- Главная графика — собственная иллюстрация из SVG. GIF собирается из её кадров существующими локальными инструментами; программы и новые зависимости не устанавливаются.
- Typography: Segoe UI / sans-serif для основной графики, Consolas / monospace для терминальных деталей. Основной README использует шрифт GitHub.
- Вертикальная компоновка без обтекания и фиксированных многоколоночных таблиц: прежний float уже ломал чтение при 390 px.
- Вся анимация сосредоточена в баннере; обложки и иконки статичны.

## Границы и проверки

Настоящий Profile README; без сайта, сервера, JS/CSS в README, workflow статистики, фальшивого online-статуса, наград и счётчиков. Старые ресурсы и история сохраняются.

Проверить GIF: число кадров, цикл, длительность, размеры и вес; просмотреть ключевые кадры. Проверить SVG/XML, лицензию и источники иконок, относительные пути, GitHub Markdown API и сохранение details/picture. Каталог и PDF не менять.

После локальной сборки показать графику и конкретный пакет публикации. Публикация — после отдельного подтверждения, затем реальная проверка 1280 и 390 px и настоящие скриншоты.

Концепция и перечисленные механики уже выбраны владельцем; этот документ фиксирует их для исполнения. Дополнительный цикл согласований обычных локальных решений не требуется.
